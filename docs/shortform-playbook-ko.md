# 숏폼 플레이북 — 유행 포맷 분해와 우리 템플릿 적용 (2026-11-01)

David 요청: "유행하는 숏폼을 마이크로 분해해서 어떤 형식으로 어떻게 어텐션을 가져오는지 연구하고 우리 숏폼에 적용". 공개된 2026년 분석 글 10여 편(출처는 끝에)과 릴스·틱톡 상위 영상의 공통 구조를 초 단위로 쪼갠 결과다. 수치는 벤더 블로그 기준이라 **방향만** 믿고, 플랫폼 공식 수치로 보지 않는다.

## 1. 유행 숏폼이 공통으로 하는 것 (초 단위)

| 구간 | 무엇이 일어나나 | 왜 | 우리 템플릿 구현 |
|---|---|---|---|
| 0.0–1.0초 | **글자 펀치 + 움직임이 동시에** — 큰 글씨가 튀어나오고 화면이 살짝 줌(1.0→1.08). 가게 이름·로고는 아직 안 나온다 | 첫 1초 안에 "스크롤 멈춤"이 결정된다. 브랜드를 먼저 보여주면 광고로 읽혀 넘어간다 | `Hook`: 단어별 팝 자막 + 줌 펀치, 브랜드는 2.5초 뒤 작게 |
| 1.0–3.0초 | 훅 문장 완성 — 질문·숫자·반전("안경 고를 때 이거 모르면 손해") | 궁금증이 생겨야 남는다 | 훅 문구는 숫자·질문·대비 중 하나를 쓴다 (sv-1 기획안 규칙) |
| 1.5–2.0초마다 | **패턴 깨기** — 컷 전환·줌 펀치·플래시·새 자막 중 하나 | 같은 화면이 2초 넘으면 이탈 | `beatFrames(bpm)` 로 1.5~2초 간격 컷, 컷마다 줌 펀치 |
| 전 구간 | **단어 단위 자막**이 화면 중앙~하단 1/3에, 한 줄 2~4단어, 핵심어만 색 | 무음 시청이 많다. 작은 하단 자막 관행은 끝났다 | `KineticCaption`: 단어 팝 + 핵심어 강조색 + 두꺼운 외곽선 |
| 중간 | **구조가 보인다** — "3가지 이유 ①②③", 비포→애프터, POV 투어 | 끝을 예측할 수 있어야 끝까지 본다 | 템플릿 4종(아래) |
| 마지막 2초 | CTA 한 줄 + 전화/주소, 첫 장면으로 **루프**되게 끝 | 저장·공유·재생 반복 | `End` 카드 + 마지막 프레임이 첫 프레임과 비슷한 톤 |

## 2. 템플릿 4종 (automation/video/src)

| 템플릿 | 구조 | 길이 | 재료(스펙·사진) | 어울리는 업종 |
|---|---|---|---|---|
| `List` — 3가지 이유 | 훅 → ①②③ 카드(사진 줌 펀치 + 번호 + 단어 팝 자막) → 엔드 | 14~16초 | highlights 3개 + 사진 3장 | 전 업종(기본값) |
| `Tour` — POV 매장 투어 | 훅 "들어가 볼까요?" → 사진 6~8장 박자 컷(장마다 한 단어 자막) → 엔드 | 10~13초 | 사진 6장 이상(photos 로 보정한 것) | 식당·카페·뷰티·매장형 |
| `BeforeAfter` — 시작 전과 지금 | 훅 → "전" 숫자(회색) → 쓸어내기 → "지금" 숫자 카운트업 → 엔드 | 11~13초 | 지표 쌍 2~3개(리뷰 수·평점·디렉토리 등) + 사진 1장 | 리포트와 같이 월 1회 |
| `Menu` — 메뉴·서비스 리빌 | 훅 → 항목 4~6개가 가격과 함께 차례로 튀어나옴(사진 배경 켄번스) → 엔드 | 12~16초 | services(이름·가격·사진) | 식당·네일·세차·학원 |
| `Promo` — 스토리(기존) | 훅 → 서비스 ≤3 → 왜 우리 → 엔드 | 20초 | 스펙 전체 | 첫 달 소개용 |

공통 장치(`Kinetic.tsx`): `KineticCaption`(단어 팝·강조색·외곽선), `Punch`(컷 시점 줌 펀치 1.0→1.08→1.0), `Flash`(컷 플래시 8프레임), `beatFrames`(bpm → 컷 프레임), `Progress`(상단 진행 바), `Brand`·`End`(Promo 와 공유).

## 3. 자막 규칙

- 한 줄 **2~4단어, 14자 이내**. 긴 문장은 `|` 로 끊어 여러 줄로 — 줄마다 1.2~2초
- 핵심어는 `*별표*` 로 감싸면 브랜드 색으로 튀어나온다(한 줄에 하나)
- 위치: 세로 중앙(훅)·하단 1/3(본문). 사진의 얼굴·글자와 겹치면 `--caption-pos top|mid|bottom` 으로 옮긴다
- 외곽선 6px + 그림자 — 밝은 사진 위에서도 읽힌다. 글꼴 Noto Sans KR 900

## 4. 루틴 사용법 (sv-2)

1. `creative.js photos --job N --out photos --ratios 9:16 --top 8` → 시트를 보고 `--pick` 으로 6~8장 확정(투어·리스트 재료)
2. `creative.js promo --job N --template list|tour|ba|menu|promo [--photos a.jpg,b.jpg,…] [--props over.json] [--bpm 100] --out x.mp4`
   - `list`: over.json 의 `reasons:[{title,sub,photo}]`(없으면 highlights) · `tour`: `--photos` 순서대로, `captions:["한 단어",…]` · `ba`: `pairs:[{label,before,after}]` · `menu`: `items:[{name,price,sub,photo}]`(없으면 services)
3. 3~4편을 `creative.js pick` 으로 올려 고객이 먼저 올릴 것을 고른다

## 5. 하지 않는 것

- 가짜 리뷰 낭독·"환자" 암시·가격 보장 문구 — 기획안 규칙 그대로
- 유행 음원 자동 삽입(저작권) — 고객이 준 mp3 만 `--music`
- 1초 미만 컷 난사 — 한인 사장님 고객층(40~60대)은 1.5초 이상이 읽힌다
