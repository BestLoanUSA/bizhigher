# 광고 표준 트리거 12개 — 구글·메타 내장 자동 규칙으로 심는다 (2026-11-02)

스마틀리 분석(세션 2026-11-02)에서 가져온 것. 스마틀리의 "Triggers"는 캠페인·광고 세트·광고 단위로 **조건이 맞으면 행동**하는 규칙이고, 구글 광고의 "자동 규칙"과 메타 Ads Manager 의 "자동화된 규칙"이 같은 모델을 무료로 제공한다. API 토큰 없이 오늘 심을 수 있다.

**원칙**
- 행동은 세 등급: **자동 실행**(안전장치·시간대·주말처럼 되돌리기 쉬운 것) · **알림만**(제외 키워드·일시정지 제안처럼 판단이 필요한 것 → David 메일 → 검증 큐) · **구축 시 1회**(설정값). §15 ③ "위험 낮은 것부터 자동 확대"와 같다
- 우선순위가 겹치면 **안전장치 > 소재 교체 > 예산 이동** 순. 같은 대상에 반대 행동을 하는 규칙은 두지 않는다
- 금액은 절대값이 아니라 **질문지 예산 기준 상대값**으로 쓴다(일예산 × 1.5, 목표 CPA × 3). ads-2 설계안이 고객 숫자로 환산한 표를 낸다
- 규칙 이름은 `BH-{번호}-{짧은이름}` (예 `BH-01-일지출상한`). 고객 계정에 남으므로 해지해도 고객 자산(약관과 일치), 우리 손을 떠난 뒤에도 사고를 막는다
- 알림 수신은 `hello@bizhigher.com`(→ david@bestloanusa.com 전달, CLAUDE.md §15)

## 2. 플랫폼에서 만드는 법

**구글 광고** — 도구 및 설정 → 대량 작업 → 규칙 → 새 규칙 → 대상(캠페인/광고그룹/키워드/광고) → 조건·기간·빈도·행동 → 이메일. 검색어 규칙(03)은 "검색어" 대상 규칙이 없으므로 토큰 전에는 주간 검색어 보고서 알림 + David 확인, 토큰 뒤에는 `ads.js propose` 가 맡는다. 광고 일정(08)은 캠페인 설정 → 광고 일정에서 요일·시간별 입찰 조정.

**메타 Ads Manager** — 모든 도구 → 자동화된 규칙 → 규칙 만들기 → 대상(캠페인/광고 세트/광고) → 조건(지출·CPA·빈도·CTR·결과) → 시간 범위 → 행동(끄기·예산 조정·알림) → 실행 주기(30분·1시간·매일). 계정당 250개 한도, Reservation 캠페인·사회 이슈 광고에는 못 쓴다. 일정(08·09)은 캠페인 예산 일정 또는 규칙으로.
