## 이 도구는 이렇게 씁니다

1. **업종**을 고르면 구글이 이해하는 세부 유형(식당은 Restaurant, 치과는 Dentist 등)이 자동으로 정해집니다.
2. **상호·웹사이트·전화번호·주소**를 구글 비즈니스 프로필과 똑같이 적습니다.
3. **영업시간**을 요일별로 넣습니다. "월요일 시간을 평일에 복사" 버튼을 쓰면 빠릅니다. 쉬는 날은 휴무에 체크하세요.
4. 식당·카페라면 음식 종류와 메뉴 페이지 주소를, 인스타·옐프 같은 등록처가 있다면 주소를 한 줄에 하나씩 넣습니다.
5. 이메일을 입력하고 **스키마 코드 만들기**를 누른 뒤, 나온 코드를 웹사이트 첫 페이지 head 안에 붙여 넣습니다.

## LocalBusiness 스키마는 무엇이고 왜 필요한가요?

**스키마는 검색엔진과 AI에게 "이 페이지는 이런 가게다"라고 정해진 형식으로 알려 주는 코드입니다.** 사람은 웹사이트를 보고 주소와 영업시간을 알아보지만, 검색엔진은 글자만 보고는 어느 숫자가 전화번호이고 어느 줄이 주소인지 헷갈릴 수 있습니다. 스키마를 넣으면 상호·주소·전화·영업시간을 정확한 "업소 정보"로 읽어 갑니다.

손님 눈에는 보이지 않지만, 구글 검색과 ChatGPT 같은 AI 검색이 가게 정보를 확인하는 근거가 됩니다. 저희가 LA·OC 한인 업소 웹사이트를 직접 확인했을 때도 이런 업소 정보가 정리된 곳은 많지 않았습니다 — [한인 업소 웹사이트 실태 조사](/data/korean-business-websites-2026-q3/).

| 항목 | 필수 여부 | 팁 |
|---|---|---|
| 상호·주소 | 필수 | 구글 비즈니스 프로필과 글자 하나까지 같게 |
| 전화번호 | 강력 권장 | +1-770-555-0123 형식으로 자동 변환됩니다 |
| 영업시간 | 강력 권장 | 같은 시간대 요일은 자동으로 묶입니다 |
| 웹사이트·대표 사진 | 권장 | 사진은 가게 외관이나 대표 메뉴 |
| SNS·등록처 주소 | 권장 | 같은 가게임을 확인시켜 줍니다 |

## 코드를 넣은 뒤 무엇을 확인해야 하나요?

붙여 넣은 뒤에는 결과 화면의 **구글 리치 결과 테스트**와 **Schema Validator** 버튼으로 오류가 없는지 확인하세요. 오류가 없다고 해서 검색 결과 모양이 바로 바뀌지는 않으며, 반영은 구글이 페이지를 다시 읽어 갈 때까지 며칠에서 몇 주 걸립니다.

**주의:** 스키마의 정보가 구글 비즈니스 프로필이나 실제 간판과 다르면 오히려 혼란을 줍니다. 이사·전화번호 변경 때는 스키마도 함께 고치세요. 별점이나 리뷰를 스키마에 직접 써 넣는 것은 구글이 자기 사이트 리뷰로 보지 않아 효과가 없고, 사실과 다르면 정책 위반이 될 수 있어 이 도구는 넣지 않습니다.

## 자주 묻는 질문

### 웹사이트 빌더를 쓰는데 코드를 어디에 넣나요?
Wix는 설정의 사용자 지정 코드에서 Head에, Squarespace는 코드 삽입(Code Injection)의 Header에, WordPress는 헤더·푸터 코드 플러그인의 Header 칸에 붙여 넣으면 됩니다. 일부 빌더는 자체적으로 업소 정보를 넣기도 하니, 넣기 전에 리치 결과 테스트로 이미 있는지 먼저 확인하세요.

### 지점이 여러 곳이면 어떻게 하나요?
지점마다 따로 코드를 만들어, 각 지점 소개 페이지에 그 지점의 코드를 넣으세요. 한 페이지에 여러 지점 주소를 섞어 넣으면 검색엔진이 어느 주소가 맞는지 헷갈릴 수 있습니다.

### 한글 상호는 어디에 들어가나요?
간판의 영문 상호를 기본 이름(name)으로, 한글 상호를 다른 이름(alternateName)으로 넣습니다. 그러면 영어로 검색하는 손님과 한국어로 검색하는 손님 모두 같은 가게로 연결됩니다.

### 하루 몇 번까지 쓸 수 있나요?
이메일을 남기시면 하루 2회까지 무료입니다. 코드는 브라우저 안에서 만들어지고, 입력하신 주소·영업시간은 서버에 저장되지 않습니다. 보관하는 것은 남겨 주신 이메일·전화번호와 상호뿐입니다.
