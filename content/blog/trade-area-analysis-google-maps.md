"우리 동네에 같은 업종이 몇 개나 있고, 그중에서 우리는 어디쯤일까?" 이 질문에 정확히 답할 수 있는 사장님은 생각보다 많지 않습니다. 상권 분석이라고 하면 비싼 컨설팅이나 유료 데이터를 떠올리기 쉽지만, 광고비를 쓰기 전에 필요한 기본 파악은 구글 지도만으로 5분이면 끝납니다. 이 글은 구글 지도에서 무엇을 어떤 순서로 보고, 그 숫자를 어떻게 판단하면 되는지 정리합니다.

## 시작 전에 준비할 것 — 시크릿 창과 검색 반경

가장 먼저 브라우저의 **시크릿(비공개) 창**을 열어 구글 지도에 접속합니다. 평소 쓰던 계정으로 보면 내 검색 기록과 자주 가는 장소가 순위에 반영되어, 손님이 실제로 보는 화면과 달라질 수 있기 때문입니다.

그다음 분석 반경을 정합니다. 업종마다 손님이 움직이는 거리가 다릅니다.

| 업종 | 참고할 반경 (대략) |
|---|---|
| 카페·분식·네일 | 차로 5~10분 / 1~3마일 |
| 일반 식당·미용실 | 차로 10~15분 / 3~7마일 |
| 치과·한의원·학원 | 차로 15~25분 / 5~15마일 |
| 한식당처럼 한인 수요가 몰린 업종 | 한인타운 전체 (손님이 멀리서도 옴) |

정답이 있는 숫자는 아닙니다. 내 손님이 실제로 사는 곳을 떠올려 정하시면 됩니다.

## 1단계 — 경쟁 가게 수 세기 (1분)

구글 지도에서 "한식당", "치과", "네일샵"처럼 **손님이 검색할 법한 업종 단어**를 입력하고, 우리 가게 중심으로 지도를 확대·축소해 정한 반경이 화면에 들어오게 맞춥니다. 화면 위에 표시되는 핀의 개수가 대략적인 경쟁 가게 수입니다.

여기서 볼 것은 두 가지입니다.

- 핀이 우리 가게 주변에 **뭉쳐 있는가, 흩어져 있는가.** 뭉쳐 있으면 손님이 비교하러 오는 상권(식당가, 치과 밀집 지역)이고, 흩어져 있으면 거리가 중요한 상권입니다.
- 한 업종이 **너무 많은가.** 핀이 수십 개라면 일반 검색어로는 순위 싸움이 치열하니, "한인", "소아", "야간진료"처럼 좁힌 검색어에서 이기는 편이 현실적입니다.

## 2단계 — 상위 5곳의 숫자를 표로 옮기기 (2분)

검색 결과 상위 5곳을 클릭해 아래 항목을 메모합니다. 종이든 스프레드시트든 상관없습니다. 우리 가게도 같은 칸에 적습니다.

| 항목 | 우리 가게 | 경쟁 1 | 경쟁 2 | 경쟁 3 | 경쟁 4 | 경쟁 5 |
|---|---|---|---|---|---|---|
| 평점 | | | | | | |
| 리뷰 수 | | | | | | |
| 최근 한 달 리뷰 수 | | | | | | |
| 사진 수 | | | | | | |
| 웹사이트 유무 | | | | | | |
| 영업시간 기재 | | | | | | |

**판단 기준은 평점보다 리뷰 수와 최신성입니다.** 평점은 4.5와 4.7의 차이가 크지 않지만, 리뷰가 1,200개인 곳과 80개인 곳은 손님에게 주는 신뢰감이 완전히 다릅니다. 리뷰 목록을 "최신순"으로 정렬하면 그 가게가 요즘도 손님이 꾸준한지 알 수 있습니다. 1년 전 리뷰가 마지막이라면 순위가 높아도 방어하기 쉬운 상대입니다.

## 3단계 — 격차를 약점과 기회로 나누기 (1분)

표를 채웠으면 우리 가게와 상위권의 차이를 두 가지로 나눕니다.

- **빠르게 좁힐 수 있는 격차:** 사진 수, 영업시간 누락, 웹사이트 링크 없음, 리뷰 답글 미작성. 이번 주에 바로 손댈 수 있습니다.
- **시간이 걸리는 격차:** 리뷰 수 자체. 하루아침에 메워지지 않으므로, 월 몇 개씩 꾸준히 쌓는 계획으로 접근해야 합니다.

반대로 **경쟁 가게의 빈틈**도 같이 찾습니다. 상위 5곳 중 웹사이트가 없는 곳이 3곳이라면 사이트를 가진 것만으로 차별화가 되고, 한국어 소개나 한국어 메뉴가 없는 곳이 많다면 한인 손님에게는 그 자체가 기회입니다. 경쟁 가게 리뷰에서 반복되는 불만("주차가 어렵다", "대기가 길다")도 우리가 반대로 내세울 수 있는 포인트입니다.

## 4단계 — 손님이 어디서 오는지 확인하기 (1분)

마지막으로 우리 가게 프로필을 열어 **'인기 시간대'**와 리뷰 속 지역 언급을 살펴봅니다. 리뷰에 "근처 회사 다니는데", "토요일에 아이 데리고" 같은 표현이 자주 나온다면 그것이 실제 주 고객층의 힌트입니다. 프로필 관리 화면에서 검색 노출 통계를 볼 수 있다면, 어떤 검색어로 우리 가게가 발견되는지도 같이 확인하세요.

한 가지 주의할 점이 있습니다. 구글 지도의 핀과 숫자는 **어디까지나 공개된 겉모습**입니다. 실제 매출, 단골 비율, 임대료 같은 내부 사정은 알 수 없고, 폐업했는데 프로필만 남은 가게나 같은 가게가 중복 등록된 경우도 섞여 있습니다. 핀 개수를 곧이곧대로 경쟁자 수로 받아들이지 말고, 상위 5곳은 반드시 직접 클릭해 확인하세요. 이 방법은 "방향을 잡는 용도"이지 정밀한 시장조사가 아닙니다.

## 5분 분석 후 체크리스트

- [ ] 시크릿 창에서 업종 키워드로 검색해 경쟁 가게 수를 파악했다
- [ ] 상위 5곳과 우리 가게의 평점·리뷰 수·최근 리뷰 수를 표로 정리했다
- [ ] 이번 주 안에 좁힐 수 있는 격차(사진, 영업시간, 웹사이트 링크)를 골랐다
- [ ] 경쟁 가게가 놓친 빈틈 한 가지를 찾았다
- [ ] 3개월 뒤 같은 표를 다시 채워 변화를 비교하기로 했다

마지막 항목이 가장 중요합니다. 상권 분석은 한 번 하고 끝내는 숙제가 아니라, 분기마다 같은 표를 다시 채워 보면서 차이가 줄어드는지 확인하는 점검 습관입니다.

## 자주 묻는 질문

### 구글 지도 말고 다른 도구도 필요한가요?

시작 단계에서는 구글 지도만으로 충분합니다. 검색량이나 방문자 수 추정이 필요하면 유료 툴이 있지만, 소상공인에게 먼저 필요한 것은 "내 주변에서 누가 어떤 숫자로 앞서 있는가"를 보는 일이고, 그건 구글 지도에 다 나와 있습니다.

### 경쟁 가게가 너무 많은데 어떻게 이기나요?

일반 검색어에서 전부 이기려 하지 마세요. "한인", "주말 영업", "소아 전문"처럼 우리만 해당되는 조건으로 검색 범위를 좁혀 보고, 그 좁은 검색에서 상위에 오르도록 프로필 설명과 사진, 리뷰를 맞추는 편이 훨씬 현실적입니다.

### 분석 결과 리뷰 수 차이가 너무 커서 따라잡기 어려워 보입니다.

리뷰 수는 단기간에 따라잡을 수 없는 지표라서, 절대 수보다 **최근 한 달 새로 달리는 리뷰 수**를 목표로 삼으세요. 월 몇 개라도 꾸준히 쌓이면 최신성 신호가 좋아집니다. 단, 대가를 주고 리뷰를 받거나 만족한 손님에게만 요청하는 방식은 구글 정책 위반이니 피해야 합니다.

### 얼마나 자주 다시 분석해야 하나요?

분기에 한 번, 연말이나 성수기 직전에 한 번 정도가 적당합니다. 새 경쟁 가게가 문을 열었거나 상위권 순위가 바뀌었는지 확인하는 정도면 충분합니다.
