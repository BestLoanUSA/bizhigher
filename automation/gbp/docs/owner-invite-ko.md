# 사장님께 드리는 안내 — 구글 비즈니스 프로필에 BizHigher를 관리자로 추가하기

구글은 **프로필 소유자(Owner)만** 관리자를 추가할 수 있게 해 둡니다. 그래서 이 작업은 사장님이 직접 하셔야 하고, 5분이면 끝납니다. 사장님의 소유권은 그대로 유지되고, BizHigher는 "관리자"로서 게시물·리뷰 답글·정보 수정만 할 수 있습니다. 프로필을 삭제하거나 소유권을 넘기는 권한은 없습니다.

## 추가할 계정

- 이메일: **hello@bizhigher.com**
- 역할: **관리자 (Manager)** — "소유자"가 아니라 "관리자"로 지정해 주세요

## 방법 1 — 휴대폰 구글 지도 앱 (가장 쉬움)

1. 구글 지도 앱을 열고 프로필 사진(오른쪽 위) → **내 비즈니스 프로필**
2. 아래로 내려 **사용자 관리** (또는 ⋯ 메뉴 → 비즈니스 프로필 설정 → 사용자 및 액세스)
3. 오른쪽 위 **＋ 추가**
4. `hello@bizhigher.com` 입력 → 역할 **관리자** 선택 → **초대**

## 방법 2 — 컴퓨터

1. 구글에서 가게 이름을 검색해 로그인된 상태로 프로필을 열고, 프로필 상단의 **⋯ (더보기)** → **비즈니스 프로필 설정**
2. **사용자 및 액세스** → **추가**
3. `hello@bizhigher.com` 입력 → **관리자** → **초대**

## 초대 뒤

- BizHigher가 초대를 수락하면 사용자 목록에 "hello@bizhigher.com · 관리자"로 보입니다.
- 기존 관리자(maxinchoi@gmail.com)는 BizHigher 쪽에서 새 계정이 정상 동작하는 것을 확인한 뒤 제거해 드리겠습니다. 당장 지우지 않으셔도 됩니다.
- 언제든 사장님이 같은 화면에서 BizHigher를 제거할 수 있습니다.

## 자주 하시는 질문

**비밀번호를 알려드려야 하나요?** 아니요. 초대만 하시면 되고, 비밀번호는 절대 묻지 않습니다.

**리뷰를 대신 써 주나요?** 아니요. 구글 정책상 금지입니다. BizHigher는 들어온 리뷰에 답글을 달고, 손님이 리뷰를 남기기 쉽게 QR을 만들어 드리는 일만 합니다.

**게시물은 아무거나 올라가나요?** 매달 한 번 게시물 계획표를 먼저 보여드리고, 승인하신 것만 올립니다.
