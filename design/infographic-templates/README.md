# 블로그 인포그래픽 템플릿 (47종)

블로그 글 1편에 이미지 1~2장을 넣기 위한 HTML 템플릿 모음. 1200×675, 브랜드 톤(남색+파랑 포인트, 세리프 제목)으로 통일돼 있다.
`sample-*.png`는 각 템플릿의 샘플 렌더. **샘플 안의 숫자·문구는 전부 예시다. 그대로 글에 쓰지 않는다.**

## 사용 순서 (루틴 필독)

1. 글의 핵심 메시지가 **구조**(순서·비교·분류)인지 **숫자**인지 정하고, 아래 표에서 용도가 맞는 템플릿 1개를 고른다. 같은 글에 2장이면 서로 다른 유형으로.
2. **최근 글 3편에 쓴 템플릿은 피한다.** `grep -rho "blog-img/[^)]*" content/blog | tail`로 최근 이미지 파일명을 보고, 파일명 끝의 템플릿 이름(`-steps` 등)이 겹치지 않게 고른다.
3. 템플릿 HTML을 스크래치 경로로 복사해 **글자·숫자만 교체**한다(CSS·구조는 유지, 레이아웃이 깨지지 않게 글자 수는 원본과 비슷하게). 같은 폴더의 `base2.css`도 함께 복사한다.
4. 렌더: `node render-one.js <복사한.html> content/blog/img/{slug}-{키워드}-{템플릿}.png` (Playwright 필요. 경로는 `PLAYWRIGHT_PATH`, 브라우저는 `CHROME` 환경변수로 지정 가능)
5. **렌더된 PNG를 반드시 열어서 본다.** 한글이 깨지거나(웹폰트 로드 실패) 글자가 겹치거나 잘리면 고치고, 못 고치면 그 이미지는 넣지 않는다. 안 좋은 이미지는 없는 것보다 나쁘다.
6. 본문에 `![설명 문장](/blog-img/파일명.png)`으로 넣는다. 빌드가 이 문장을 alt와 캡션으로 쓴다.
   - **설명 문장**: 이미지가 무엇을 보여주는지 한 문장(키워드 나열 금지). 예: `구글 프로필 카테고리를 고르는 4단계 순서도`
   - **파일명**: 영문 소문자·하이픈, `{slug}-{핵심키워드}-{템플릿}.png`. 예: `google-business-profile-category-steps.png`
   - **위치**: 1장이면 첫 `##` 섹션 안(핵심 내용 바로 옆), 2장이면 앞/중간. 요약 박스·FAQ 안에는 넣지 않는다.
   - 이미지가 전달하는 내용은 **본문 글에도 있어야 한다**(이미지 속 글자만으로 검색에 걸리지 않는다). 이미지는 글을 보강하는 것이지 대신하는 것이 아니다.
7. 이미지 파일은 글과 **같은 커밋**에 포함한다(`git add content/blog/img`).

## 숫자·사실 규칙 (어기면 이미지를 넣지 않는다)

- **지어낸 수치 금지.** 글 본문 또는 공식 출처에 있는 숫자만 넣는다. 출처가 있으면 이미지 하단에 작게 `출처: 기관명, 기준일`을 넣는다(`.note` 클래스).
- 숫자가 근거 없는 "예시"라면: ① 가능하면 숫자 없는 **구조형** 템플릿으로 바꾼다. ② 꼭 필요하면 `SAMPLE DATA` 태그를 `EXAMPLE · 가상의 수치`로 바꿔 **남겨 둔다**. 태그를 지우는 것은 실제 출처가 있을 때만.
- 숫자형 이미지에 우리 고객 사례·성과를 쓰지 않는다(실제 고객 데이터가 없다).
- 특정 업체·브랜드의 로고·상표·실제 화면을 흉내 내지 않는다. 구글 화면 캡처처럼 보이게 만든 가짜 화면 금지.
- 리뷰 대가 제공·게이팅·가짜 리뷰를 긍정적으로 묘사하는 이미지 금지. 의료·치과 글은 환자 여부를 암시하지 않는다.
- 판매 문구·가격·"문의하세요" 금지(CTA는 빌드가 붙인다). 이미지 하단의 BizHigher 표기만 허용.

## 만들지 않는 것 (판단 기록)

| 요청된 형태 | 판단 |
|---|---|
| 사진 | 실제 가게 사진은 David만 제공 가능. AI 생성 "가짜 가게 사진"은 신뢰 문제로 쓰지 않는다 |
| GIF·모션 그래픽·비디오 | 제작은 가능하나 SEO 효과가 작고 용량이 크다. 숏폼 영상 파이프라인(§19-5)과 함께 별도 과제 |
| 인터랙티브 대시보드·3D·AR/VR | 정적 블로그 글에 맞지 않음 |
| 실제 지도(단계 구분도) | 지역별 실데이터가 없다. 확보되면 추가 |
| 실제 화면 캡처 | 로그인·약관 문제로 루틴이 못 찍음. 글에 "스크린샷 필요" 메모만 남기고 David가 제공 |

## 새 템플릿을 추가할 때

`base2.css`의 변수·클래스(`.w .k h1 .lead .foot .tag .note`)를 쓰고, 1200×675 안에서 하단 푸터 선(y≈620) 위로 요소가 넘치지 않게 한다. 렌더 후 이미지를 열어 겹침을 확인하고 `sample-*.png`와 이 표를 함께 갱신한다.
